# C++ Coding

My C++ practice problems and solutions, collected from competitive programming platforms.

## Contents

| Folder | Topics |
| --- | --- |
| `Basic Problem Solving` | Loops, conditions, basic I/O |
| `C++ Recap` | Core language fundamentals |
| `STL 1`, `STL 2` | Standard Template Library |
| `Data structure` | Stack, queue, trees |
| `Linked List`, `doubly linked list`, `Binary Tree` | Data structures practice |
| `Algorithm Graph` | Graph algorithms (DFS, BFS, etc.) |
| `Two pointer problem` | Two-pointer technique |
| `codeforces contest` | Codeforces problems |
| `Code chef problem solving` | CodeChef problems |
| `At coder contest.cpp` | AtCoder problems |
| `CSES Problem Solving` | CSES problems |
| `xpsc week 1–4` | Weekly practice sets |
| `CityFix` | Smart problem reporting & resolution system |
| `Week2`, `dsa assignment` | Coursework |

Standalone practice files (arrays, dynamic memory, pointers, recursion, etc.) sit in the root folder.

## Build

Compiled with MinGW-w64 g++:

```bash
g++ filename.cpp -o filename
./filename
```

## Note

Compiled binaries (`*.exe`, `*.o`), `.vscode/` and `.cph/` folders are excluded via `.gitignore` — only source files are tracked.
